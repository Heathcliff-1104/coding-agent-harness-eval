# 评分规则

## 需求完成度：45 分

- 登录、注册、权限与日志：8
- 入库流程：7
- 出库与 BOM：10
- 库存、预警、流水与 CIS：8
- 报表统计：5
- 用户、角色、备份、日志与密码管理：7

## 正确性与安全：25 分

- 13 个外部验收测试：15
- 权限边界、库存不变量、并发与密钥处理的源码/运行复核：10

## 构建与测试工程：15 分

- 后端干净构建和前端生产构建。
- 自带测试的数量、覆盖范围和断言质量。
- 前后端 API 合同。
- 文档是否与实际行为一致。
- 是否存在前端自动化测试。

## 真实页面可用性：10 分

- 根路径和登录页。
- 登录后的主框架与动态菜单。
- 入库、出库、库存预警、报表、用户与角色页。
- 前端可见故障和后端运行错误。

## 过程与可复现性：5 分

- 是否保留基线身份。
- Git 提交、补丁和结果是否可恢复。
- 是否破坏隔离边界。
- 轨迹和结果体积是否合理。
- 是否如实记录配置与限制。

评分不是代码行数排名。读者可以使用 `evaluation/scorecard.csv` 和公开证据按自己的权重重新计算。
